1. **Retrospective session run**

2. **Actionable outcomes**

3. **Artifact saved**  
   - Given the retrospective completes  
   - When notes are saved  
   - Then a retro summary/action list is stored in `docs/sprint-artifacts/epic-1-invoice-accounting-core/retrospective.md` (or similar), linked from sprint-status/project-context.

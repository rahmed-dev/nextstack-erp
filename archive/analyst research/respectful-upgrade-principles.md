# Philosophy
Earn upgrades through delivered value; never nag. Core stays fully usable offline. Upsell is transparent, optional, and contextual.

# Practices
- Let work speak: show upgrade only after a clear win (e.g., overdue cleared → “Insights can show collections trend”). Make it dismissible.
- Gentle affordances: lock icon on premium reports with a short explainer; no timers, no pop-ups.
- Trust cues: CSV exports always free; watermark only PDFs/visuals until upgraded; offline always works.
- Delayed trials: start trial only when user opts to view premium after real data exists (>1 invoice + 1 payment).
- Reciprocity triggers: “3 invoices paid—see profitability by client?” Single-click, opt-in trial.
- Settings respect: allow disabling upgrade hints.
- Outcome framing: “Collections automation helps you get paid faster” vs “Upgrade now.”
- Earned expansions: grant 7-day Insights when they import customers, reconcile a payment, or clear all overdue—opt-in.
- Gratitude tone: “If this saved you time, Insights adds dashboards; optional.”
- Transparency: publish exact free vs paid list; remind “Your data stays local; paywall is only for advanced views/automation.”

# In-Product Copy & Placement Guidelines
- Placement: small inline text/link near the locked control; never a modal. Example under A/R list: “Aging buckets in Insights (optional).”
- Language: outcome-led, optional. E.g., “See overdue by client (Insights) — optional upgrade.”
- Frequency: show at most once per session per surface; remember dismissals.
- Trial trigger copy: “Want to see this once? Start a 7-day Insights pass; your core stays free.”
- Post-success prompt: after reminder sent/paid: “Nice—collections trend available in Insights if you want it.”
- Settings toggle: “Hide upgrade suggestions” to respect user choice.
- Receipts/exports: footer line only, e.g., “PDF branding and dashboards are part of Insights (optional).”
